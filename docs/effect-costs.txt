RGB Matrix effect cost measurements - Sofle rev1 keymap, 2026-10-05
==================================================================

Method: starting from the then-current config.h (27852/28672, only
SOLID_REACTIVE_SIMPLE enabled), each effect below was added in turn and a full
`qmk compile` run, recording the resulting size. "delta" is the marginal cost of
that effect on top of everything listed before it - i.e. it includes the effect's
own code only where the linker did not already have it.

Caveat: the deltas are NOT additive. Effects share runner/math code, so an effect
added later can be much cheaper (MULTI* variants: 8 B) than the first one that
pulls in the runner (SOLID_REACTIVE_WIDE: 462 B, which pays for the splash
runner). Moving an effect earlier in the list, or enabling a variant without the
effect that provided the runner, changes the numbers.

Every size above 28672 is a build that failed the size check and would have to be
trimmed; the measurement continued past the limit only because the loop kept
adding effects and the size check does not stop the compile from producing a
number.

Not measured: SOLID_COLOR (always compiled), the two framebuffer effects
(TYPING_HEATMAP, DIGITAL_RAIN) - they additionally need
RGB_MATRIX_FRAMEBUFFER_EFFECTS, i.e. 216 B of the ATmega32u4's 2560 B RAM, which
is why they are excluded from this keymap.

Final enabled set (28614/28672, 58 B free):
  SOLID_REACTIVE_SIMPLE (default), SOLID_REACTIVE, SOLID_REACTIVE_WIDE,
  SOLID_REACTIVE_MULTIWIDE, SPLASH, SOLID_SPLASH, MULTISPLASH,
  SOLID_MULTISPLASH, CYCLE_LEFT_RIGHT

Combining them again gave 28676 (4 B over) with CYCLE_UP_DOWN added, so that one
was dropped: the deltas above really are order-dependent.
